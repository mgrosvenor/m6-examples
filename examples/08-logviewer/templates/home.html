Log Viewer Demo

This example adds a real-time log viewer to the m6 stack.

All processes write structured JSON logs to stdout. In development, dev.sh redirects each process's stdout to a file in logs/. The log viewer tails those files via m6-file's tail mode and displays new entries as they arrive.
