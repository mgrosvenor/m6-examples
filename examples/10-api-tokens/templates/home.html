What is an API token?

API tokens are long-lived JWTs that allow scripts and services to call protected endpoints without a browser session. Unlike session cookies (which expire in minutes), an API token can be valid for days or months.

How it works

  1. An admin creates a token with m6-auth-cli token create.
  2. The token is a signed JWT. Copy it once — it is never stored in plain text.
  3. Pass it as Authorization: Bearer <token> in each request.
  4. m6-http verifies the signature and enforces the require rule.
  5. When the token is no longer needed, revoke it with m6-auth-cli token revoke.

Try it

# Create a token for the 'api' user (created by setup.sh)
m6-auth-cli configs/m6-auth.conf token create api --name mytoken

# Call the protected endpoint
curl -sk https://localhost:8443/api/data \
     -H "Authorization: Bearer <paste token here>"
