Manage API tokens

Use the CLI to create, list, and revoke tokens:

# List tokens for your account
m6-auth-cli configs/m6-auth.conf token ls {{ auth.username }}

# Create a new token (30-day TTL)
m6-auth-cli configs/m6-auth.conf token create {{ auth.username }} \
    --name my-script --ttl-days 30

# Revoke a token by ID
m6-auth-cli configs/m6-auth.conf token revoke <token-id>
